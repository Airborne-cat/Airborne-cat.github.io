1. CNN 이전의 Image Classification

Neural Network

1. Linear Classifier

  • 이미지를 벡터로 flatten하여 입력으로 처리한다.
  • Linear Classifier는 클래스마다 하나의 template만 학습할 수 있다.

2. MLP (FNN)

  • 마찬가지로 이미지를 벡터로 flatten하여 입력으로 처리한다.
    • 예: $32 \times 32 \times 3 \rightarrow 3072$
  • 그 과정에서 픽셀 사이의 공간적 관계가 파괴된다.
  • 입력 차원이 이미지의 픽셀 수에 비례하므로 파라미터 수가 많아져 학습이 어려워진다.

Hand-crafted Features

1. Color Histogram

  • 이미지의 색 분포를 바탕으로 이미지를 분류한다.
  • 표현력이 제한적이며 공간적 형태 정보를 담지 못한다.

2. HOG (Histogram of Oriented Gradients)

  1. Edge를 검출한다.
  2. $8 \times 8$ cell 단위에서 방향을 9개의 bin으로 나누어 히스토그램으로 표현한다.
  3. Cell을 합쳐 $16 \times 16$ block을 만들고 정규화한다.
  4. 추출한 feature에 머신러닝 기법을 적용하여 classification을 수행한다.

3. Bag of Visual Words

  1. 이미지에서 patch를 추출한다.
  2. Patch들을 clustering하고 cluster 중심을 visual word로 설정한다.
  3. 각 이미지의 visual word 분포를 히스토그램으로 표현한다.
  4. 추출한 feature에 머신러닝 기법을 적용하여 classification을 수행한다.

2. CNN의 등장

Motivation

  • CNN 이전에는 사람이 직접 feature를 설계해야 했다.
  • CNN은 feature extraction 자체를 데이터로부터 학습한다.
  • FNN과 달리 공간 정보를 유지하기 위해 국소적인 patch 단위로 연산한다.

CNN의 역사

1. LeNet (1998)

2. AlexNet

LeNet과 AlexNet의 주요 차이는 다음과 같다.

ViT는 CNN이 아닌 Transformer 기반의 이미지 모델이다.

3. CNN Architecture

$(\text{Convolutional Layer} + \text{Pooling} + \text{Activation}) \times N$
$\rightarrow \text{FNN} \rightarrow \text{Softmax + Cross Entropy}$

3.1 Convolutional Layer

  • 입력 데이터를 flatten하지 않고 공간 구조를 유지한다.
  • $11 \times 11$, $5 \times 5$, $3 \times 3$ 등의 filter를 국소 영역에 적용한다.

하나의 patch와 filter의 파라미터를 element-wise로 곱한 뒤 모두 더한다.

  • 각 국소 영역에 동일한 선형 변환을 적용하는 것과 같다.
  • 하나의 입력에 여러 filter를 적용하며 출력 channel 수는 filter 수와 같다.
  • 동일한 filter가 전 영역에서 같은 파라미터를 사용한다. 이를 weight sharing이라고 한다.
  • Weight sharing 덕분에 입력의 높이와 너비가 커져도 filter 자체의 파라미터 수는 증가하지 않는다.

주요 용어

  • Padding: 가장자리에 값을 추가하여 출력의 spatial size를 조절하고 경계 정보를 보존한다.
  • Stride: Filter가 한 번에 이동하는 칸 수이다.
  • Window: Filter가 한 번에 보는 patch 영역이다.
  • $1 \times 1$ Convolution: Spatial size를 유지하면서 channel 수를 조절할 수 있다.
  • Receptive Field: 특정 activation에 영향을 주는 입력 이미지 영역이다.

CNN의 Inductive Bias

  • 초기 layer는 edge, 색, texture 같은 low-level feature를 추출한다.
  • 깊은 layer에서는 low-level feature를 결합해 더 넓은 영역과 의미를 표현하는 higher-level representation을 학습한다.
  • 이 구조에는 다음과 같은 inductive bias가 있다.
  1. Locality bias: 가까운 픽셀끼리 더 중요한 관계를 가진다고 가정한다.
  2. Translation equivariance: 입력이 이동하면 convolution의 feature map도 같은 방향으로 이동한다.

단일 convolutional layer는 translation equivariance를 가진다. 여러 layer와 pooling 또는 downsampling을 거치면 작은 위치 변화에 대한 출력 민감도가 감소하여 근사적인 translation invariance와 robustness를 얻을 수 있다.

3.2 Max Pooling

  • 특정 patch에서 가장 큰 activation만 전달한다.
  • Spatial resolution과 계산량을 줄인다.
  • 작은 위치 변화에 대한 민감도를 낮추는 데 도움을 준다.
  • 학습되는 파라미터는 없다.

3.3 Activation Function: ReLU

ReLU는 convolution 결과에 비선형성을 추가한다.

3.4 FNN + Softmax + Cross Entropy

Convolutional backbone이 추출한 feature를 FNN에 전달하고, softmax로 클래스 확률을 계산한 뒤 cross-entropy loss로 학습한다.

4. Conclusion

  1. 왜 MLP보다 CNN이 이미지에 적합한가?
    Spatial structure, local connectivity, weight sharing을 활용하기 때문이다.

  2. Filter depth는 어떻게 정해지는가?
    항상 input channel 전체를 덮는다.

  3. Filter 수를 늘리면 무엇이 바뀌는가?
    Output channel 수가 증가한다.

  4. Padding의 목적은 무엇인가?
    Spatial size를 조절하고 boundary information을 처리한다.

  5. Stride를 증가시키면 어떻게 되는가?
    Spatial resolution이 감소한다.

  6. Pooling parameter는 학습되는가?
    아니다.

  7. Convolution의 parameter 수에 input의 $H$, $W$가 들어가는가?
    아니다. Weight sharing 때문이다.

  8. Receptive field란 무엇인가?
    특정 activation에 영향을 주는 input 영역이다.

  9. Translation equivariance와 invariance의 차이는 무엇인가?
    Equivariance는 입력의 이동이 출력의 동일한 이동으로 이어지는 성질이고, invariance는 입력이 이동해도 최종 출력이 거의 변하지 않는 성질이다.
