Neural Networks and Backpropagation

본 내용은 CS231n Lecture 4.의 내용을 재구성 한 것임

1. Neural Network(인공신경망)

: Perceptron을 쌓아서 학습하는 머신러닝 모델

인공신경망은

Input Layer –> Hidden Layer –> Output Layer

로 구성되어 있음.

  1. Input Layer
    입력 데이터를 받아서 Hidden Layer로 보내는 역할
  2. Hidden Layer
    학습이 이뤄지는 곳(파라미터가 존재하는 곳), 한 층의 모든 뉴런들은 다음 층의 모든 뉴런들과 연결되어 있어 이러한 구조를 FNN(Fullyy Connected Network)라고도 부름
  3. Output Layer
    최종 예측 결과를 내는 층.

2. Hidden Layer

한 Hidden Layer에서 입력 데이터가 모든 뉴런들에 대해 연결되어 있는 것은

와 같이 Linear Trasformation의 형태로 나타낼 수 있음(Bias는 설명의 편의를 위해 생략)

여기에 Hidden Layer를 2개 쌓는다면 와 같은 형태가 될 것임. 그런데 라고 정의하면 의 형태가 되어 층을 아무리 쌓아도 여전히 하나의 Linear Transformation과 동일 함

이를 해결하기 위해 다음과 같이 Layer 사이사이에 Non-linearity를 추가하는데 이를 Activation Function이라 함

Activation Fuction(활성화 함수)

  1. ReLU Class가 고정된 Classification 문제에 강함 (AlexNet에서 처음으로 CNN에 적용)
    • Backpropagation 연산 단순(0보다 크면 입력 그대로, 아니면 0 전송)
    • 0에서 미분 안돼서 예외 처리 해줘야 됨
    • Backpropagtion에서 한 번 0되면 쭉 0이라 Gradient Vasnishing 문제 발생 –> 초기 Layer의 학습 어려움

  2. Leaky ReLU ReLU에서 발생하던 Gradient Vanishing문제를 해결하고자 함

  3. Sigmoid 옛날에 쓰던 거임
    • 0 Centering이 안돼있음
  4. Tanh

Output Layer(출력 함수)

$Loss\ Function + Output\ Activation\ Function$

Output Layer에 관한 설명은 Lecture 3. 참고

3. Back Propagation(오차역전파)

Computational Graph

함수 $f$는 위와 같이 두 개의 Operation으로 쪼갤 수 있음. 그리고 이는

x ─┐
   +→ q ─┐
y ─┘     × → f
z ───────┘

와 같이 그래프로 표현할 수 있는데 이를 Computational Graph라 부름.

Computational Graph: 함수를 Operation 단위로 쪼개서 이를 그래프로 표현한 것

Back Propagation

Backpropagation이란?

Chain Rule을 Computational Graph에 반복 적용

FNN은 행렬 연산과 활성화 함수의 중첩이므로 NN 전체를 Computational Graph로 표현할 수 있음. 이에 Loss Function에 대한 각 가중치의 기울기를 구해 가중치 갱신을 진행하고자 Back Propagtion을 진행함.

각 Gate들의 Gradient Flow

https://cs231n.stanford.edu/slides/2026/lecture_4.pdf 위 PDF는 cs231n 공식 슬라이드 자료임. 48p.~94p.까지 자세하게 설명되어 있으므로 참고 바람

여기서 모델 구현 시 중요한 점은

  1. 순전파 과정에서 역전파에 필요한 값을 cache하도록 설정
  2. 1 : 1로 연산이 이뤄지는 활성화 함수의 경우 하나의 Gate로 취급하여 역전파 연산을 함 ex) Cross-entrophy Loss + Softmax 역전파 연산 –> Target y - Prediction y
  3. 벡터 미분 시 Jacobian 행렬 전체를 만드는 것은 비효율적 –> Jacobian-vector Product를 Implicit하게 자동 미분하도록 해야 함
