1. Image Classification이란?

Image Classification은 입력 이미지가 어떤 클래스에 속하는지를 구분하는 문제이다.

사람에게는 비교적 간단한 문제지만, 컴퓨터는 이미지를 가로 × 세로 × 3 크기의 pixel tensor로 바라본다. 이 때문에 이미지의 픽셀 값과 사람이 이해하는 의미 사이에 Semantic Gap(의미적 간극)이 발생한다.

Image Classification의 주요 Challenge

  • Viewpoint: 카메라 각도
  • Illumination: 조명
  • Scale: 크기
  • Background clutter: 배경
  • Occlusion: 가려짐
  • Deformation: 자세 변화
  • Intraclass variation: 같은 클래스 내부의 모양 차이

2. How To Do Classification

초기 Computer Vision

초기 CV에서는 사람이 직접 특징과 규칙을 설계하는 방식이 사용되었다.

Edge detect → Corner detect → Find pattern

즉, 사람이 직접 규칙을 작성하는 Hard Coding 방식이다.

Data-Driven Approach

Data-Driven Approach에서는 사람이 규칙을 직접 작성하는 대신, 학습 알고리즘이 데이터로부터 규칙을 획득한다.

Collect Data → Train → Evaluate

2.1 KNN Classification

KNN은 새로운 이미지와 모든 training image 사이의 거리(distance)를 계산한 뒤, 가장 가까운 k개의 training image를 이용해 클래스를 결정한다.

\[i^* = \arg\min_i d(x, x_i)\]

즉, 새로운 이미지와 가장 비슷한 training image가 무엇인지 찾는 방식이다.

KNN 모델의 한계

1. Outlier에 민감함

k를 너무 작게 설정하면 가장 가까운 하나의 데이터에 크게 의존한다. 따라서 보통 k > 1로 설정하고 Majority Voting 방식을 사용할 수 있다.

이처럼 training 과정에서 직접 학습되지 않고 사람이 설정해야 하는 값들을 하이퍼파라미터(hyperparameter)라고 한다.

  • Learning rate
  • Batch size
  • Hidden dimension
  • k in KNN

2. Prediction Cost

  • Training: O(1) — training data를 기억하는 것 외에는 별도의 학습 과정이 거의 없음
  • Test: O(n) — 새로운 입력마다 training data 전체와 비교해야 함

즉, training은 빠르지만 prediction 비용이 크다.

2.2 Linear Classifier

Linear Classifier는 training data 전체를 저장하는 대신, 데이터의 정보를 파라미터 $W$에 압축한다.

Linear Classifier를 바라보는 3가지 관점

1. Class Score 측정

각 클래스에 대한 score $s_j$를 계산한다.

2. $W$를 Class Template으로 해석

Linear mapping은 $W$와 입력 $x$ 사이의 유사도를 확인하는 방식으로 볼 수 있다.

다만 Computer Vision 문제에서는 하나의 클래스도 여러 형태의 template을 가질 수 있기 때문에, 하나의 template만 표현하는 Linear Classifier에는 한계가 있다.

3. 모델 학습 및 하이퍼파라미터 튜닝

KNN에서 k를 어떻게 설정할 것인가?

Training data에서 가장 잘 작동하는 값 선택

예를 들어 k = 1이 training data에서 가장 좋은 성능을 보일 수 있다.

하지만 training data에 지나치게 맞춰질 경우 generalization이 낮아지고 Overfitting이 발생한다.

Test data에서 가장 잘 작동하는 값 선택

Test data를 이용해 하이퍼파라미터를 선택하면 test 정보가 training 과정에 포함되는 셈이므로 Data Leakage가 발생한다.

Validation Dataset 설정

Dataset 역할
Training Dataset 모델 학습
Validation Dataset 학습 과정에서 하이퍼파라미터 및 objective 관련 선택
Test Dataset 모델의 최종 accuracy 측정

K-fold Cross Validation

데이터의 크기가 작은 경우 사용할 수 있다.

  1. Training data를 k개로 나눈다.
  2. 그중 하나를 validation data로 사용한다.
  3. 서로 다른 split에 대해 총 k번 반복한다.
  4. 각 결과의 평균을 모델 성능으로 사용한다.

4. Softmax + Cross-Entropy Loss

Softmax

Softmax는 logit을 각 클래스에 대한 확률 분포로 변환한다.

Cross-Entropy Loss

Cross-Entropy Loss는 모델의 Objective(목적함수)로 사용된다. 모델은 loss가 작아지는 방향으로 학습한다.

Likelihood(우도)

  • 학습 데이터 $X$가 주어졌을 때 사건 $y$가 나타날 확률과 연결해서 이해할 수 있다.
  • 모델의 objective를 설계할 때는 likelihood를 최대화하는 방향으로 설계한다.

Summary

  • Image Classification에는 픽셀과 의미 사이의 Semantic Gap이 존재한다.
  • Data-Driven Approach는 데이터로부터 분류 규칙을 학습한다.
  • KNN은 단순하지만 prediction cost가 크고 하이퍼파라미터 k 선택이 중요하다.
  • Linear Classifier는 데이터를 파라미터 $W$로 압축해 class score를 계산한다.
  • 하이퍼파라미터 선택에는 training/test가 아닌 validation set을 사용해야 한다.
  • Softmax는 logit을 확률 분포로 변환하고 Cross-Entropy는 학습 objective로 사용된다.
