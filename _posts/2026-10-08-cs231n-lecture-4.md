## Neural Networks and Backpropagation
*본 내용은 CS231n Lecture 4.의 내용을 재구성 한 것임*

![Neural Network 구조]({{ '/assets/img/cs231n/lecture-4/Pasted%20image%2020261002185254.png' | relative_url }})
## 1. Neural Network(인공신경망)
: Perceptron을 쌓아서 학습하는 머신러닝 모델

인공신경망은
> *Input Layer --> Hidden Layer --> Output Layer*

로 구성되어 있음.

1. Input Layer
	: 입력 데이터를 받아서 Hidden Layer로 보내는 역할
2. Hidden Layer
	: 학습이 이뤄지는 곳(파라미터가 존재하는 곳), 한 층의 모든 뉴런들은 다음 층의 모든 뉴런들과 연결되어 있어 이러한 구조를 FNN(Fullyy Connected Network)라고도 부름
3. Output Layer
	: 최종 예측 결과를 내는 층.

## 2. Hidden Layer
한 Hidden Layer에서 입력 데이터가 모든 뉴런들에 대해 연결되어 있는 것은
> ![Hidden Layer 연결]({{ '/assets/img/cs231n/lecture-4/Pasted%20image%2020261002190943.png' | relative_url }}) ![Linear Transformation]({{ '/assets/img/cs231n/lecture-4/Pasted%20image%2020261002190950.png' | relative_url }})

와 같이 Linear Trasformation의 형태로 나타낼 수 있음(Bias는 설명의 편의를 위해 생략)

여기에 Hidden Layer를 2개 쌓는다면 ![두 Hidden Layer의 연산]({{ '/assets/img/cs231n/lecture-4/Pasted%20image%2020261002191240.png' | relative_url }})와 같은 형태가 될 것임.
그런데 ![선형 변환의 결합]({{ '/assets/img/cs231n/lecture-4/Pasted%20image%2020261002191329.png' | relative_url }})라고 정의하면 ![결합된 선형 변환]({{ '/assets/img/cs231n/lecture-4/Pasted%20image%2020261002191343.png' | relative_url }})의 형태가 되어 **층을 아무리 쌓아도 여전히 하나의 Linear Transformation과 동일 함**

이를 해결하기 위해 다음과 같이 Layer 사이사이에 Non-linearity를 추가하는데 이를 **Activation Function이라 함**
> ![Activation Function 적용]({{ '/assets/img/cs231n/lecture-4/Pasted%20image%2020261002191529.png' | relative_url }})

## 3. Back Propagation(오차역전파)

### Computational Graph
<img src="{{ '/assets/img/cs231n/lecture-4/Pasted%20image%2020261004150435.png' | relative_url }}" alt="Computational Graph 함수" width="164">
함수 $f$는 위와 같이 두 개의 Operation으로 쪼갤 수 있음. 그리고 이는

```text
x ─┐
   +→ q ─┐
y ─┘     × → f
z ───────┘
```

와 같이 그래프로 표현할 수 있는데 이를 **Computational Graph**라 부름.

> **Computational Graph:** 함수를 Operation 단위로 쪼개서 이를 그래프로 표현한 것

### Back Propagation
Backpropagation이란?
> **Chain Rule을 Computational Graph에 반복 적용**

FNN은 행렬 연산과 활성화 함수의 중첩이므로 NN 전체를 Computational Graph로 표현할 수 있음. 이에 Loss Function에 대한 각 가중치의 기울기를 구해 가중치 갱신을 진행하고자 Back Propagtion을 진행함.
